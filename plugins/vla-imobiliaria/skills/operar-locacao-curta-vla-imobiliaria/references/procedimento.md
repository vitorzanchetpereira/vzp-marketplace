## 1. Objetivo e Aplicação

### Objetivo

Padronizar o atendimento e a operação de locações de curta temporada (estadias de 1 a 90 dias) administradas pela VLA Imobiliária e parceiros, garantindo previsibilidade, segurança jurídica, satisfação do hóspede e proteção do patrimônio do proprietário.

### Aplicação

Este POP aplica-se a todos os imóveis sob gestão da VLA Imobiliária destinados a locação por temporada, incluindo:

- Chácaras Rio Celeste (uso de lazer e fim de semana);

- Imóveis urbanos residenciais (apartamentos, casas, kitnets);

- Imóveis comerciais destinados a uso temporário (eventos, residência executiva).

### Base Legal

- Lei nº 8.245/1991 (Lei do Inquilinato), art. 48 a 50 — locação por temporada;

- Código Civil Brasileiro (Lei nº 10.406/2002), arts. 565 a 578;

- Código de Defesa do Consumidor (Lei nº 8.078/1990), quando aplicável;

- Lei Geral de Proteção de Dados (Lei nº 13.709/2018) — LGPD.

## 2. Definições e Conceitos

| TERMO | DEFINIÇÃO |
| --- | --- |
| Curta Temporada | Locação por prazo igual ou inferior a 90 dias, conforme art. 48 da Lei nº 8.245/91. |
| Hóspede / Locatário | Pessoa física ou jurídica que contrata o uso temporário do imóvel. |
| Proprietário / Locador | Titular do imóvel, representado pela VLA Imobiliária em regime de administração. |
| Caução | Valor depositado pelo hóspede como garantia contra danos, retido até a vistoria de saída. |
| Vistoria | Inspeção formal e fotográfica do imóvel em entrada (in) e saída (out). |
| Check-in / Check-out | Momentos formais de entrada e saída do hóspede no imóvel. |
| SLA | Service Level Agreement — prazo máximo definido para resposta ou ação. |
| Reserva Instantânea | Configuração do Airbnb que confirma a reserva automaticamente, sem aprovação manual do anfitrião. |
| AirCover | Proteção gratuita do Airbnb ao anfitrião contra danos de até USD 3 milhões por reserva. |
| Taxa de Serviço Airbnb | Taxa cobrada do hóspede pela plataforma (≈14%). O anfitrião paga ≈3% deduzido automaticamente. |
| Lead | Contato de interessado em reservar o imóvel, antes da confirmação. |

## 5.1 Captação e Pré-Reserva — Roteiro Comercial

Objetivo da Etapa

Receber o lead, qualificar a demanda, validar disponibilidade e enviar proposta formal em até 2 horas úteis — sem perder a venda e sem correr riscos desnecessários.

| ✓ PRINCÍPIO CENTRAL DESTA ETAPA |
| --- |
| Resposta rápida = conversão alta. O hóspede que não recebe resposta em até 2h |
| geralmente já fechou com outro imóvel. Velocidade é o principal diferencial no atendimento |
| de curta temporada. |

### Canais de Entrada e Registro

O lead pode chegar por: WhatsApp comercial, e-mail, site, indicação, plataformas (Airbnb/Booking) ou contato presencial. Toda entrada é registrada no CRM/planilha de leads no mesmo dia.

#### Airbnb — Gestão de Leads pela Plataforma

| AIRBNB — CAPTAÇÃO E RESPOSTA |
| --- |
| Leads via Airbnb chegam pela Caixa de Entrada (Inbox) do app/site — não por WhatsApp. |
| SLA Airbnb: responder em até 24h. Atrasos reduzem a taxa de resposta e penalizam o ranking. |
| • Reserva Instantânea ativa: reserva confirmada automaticamente, sem aprovação manual. |
| • Aprovação manual: anfitrião tem 24h para aceitar ou recusar o pedido do hóspede. |
| → Configurar mensagem automática de boas-vindas para disparar a cada confirmação de reserva. |
| → Para aprovação manual: verificar perfil do hóspede (avaliações, identidade verificada, histórico). |
| → Recusar reservas repetidamente prejudica o posicionamento — manter calendário sempre atualizado. |

### Roteiro de Atendimento — Passo a Passo

#### PASSO 1 — Saudação e Apresentação

| COMO FAZER |
| --- |
| "Olá, [Nome]! Aqui é [seu nome] da VLA Imobiliária. Que bom que entrou em contato!" |
| "Vi que você tem interesse no [imóvel]. Posso te ajudar a verificar disponibilidade |
| e te enviar mais detalhes. Pode me contar um pouco mais sobre o que você precisa?" |
| Dicas: |
| • Responder com o nome do cliente (se souber) — gera conexão imediata. |
| • Tom: caloroso, profissional, sem pressão. |

#### PASSO 2 — Qualificação (levantar informações-chave)

Fazer essas perguntas de forma natural, não como formulário:

| PERGUNTA | POR QUE PERGUNTAR |
| --- | --- |
| "Qual imóvel te chamou atenção? Ou posso te ajudar a escolher?" | Identificar o imóvel de interesse ou direcionar para a carteira. |
| "Quais seriam as datas de entrada e saída?" | Verificar disponibilidade e calcular o total. |
| "Quantas pessoas vão usar o imóvel? Tem crianças?" | Validar capacidade máxima. Locações com excesso são recusadas. |
| "Qual a finalidade da estadia — lazer, trabalho, evento?" | Imóveis para eventos têm regras específicas. Identificar riscos. |
| "Como prefere manter contato — WhatsApp ou e-mail?" | Canal preferencial para toda a comunicação posterior. |

| ⚠ FILTROS OBRIGATÓRIOS — VERIFICAR ANTES DE AVANÇAR |
| --- |
| Número de pessoas: nunca confirmar reserva que ultrapasse a capacidade máxima do imóvel. |
| Finalidade 'evento': acionar gerência antes de prosseguir — imóveis residenciais não são |
| autorizados para festas sem aprovação específica. |
| Alta temporada (jul, dez, jan, feriados): reduzir validade da proposta para 24h. |

#### PASSO 3 — Consulta de Disponibilidade e Oferta

- Verificar calendário do imóvel imediatamente;

- Se disponível: confirmar e avançar para envio de proposta;

- Se indisponível: oferecer 1 a 2 alternativas equivalentes — nunca encerrar com um 'não' simples;

- Bloquear data por até 48h como pré-reserva (registrar no calendário como "PRÉ-RESERVA + nome").

| COMO OFERECER ALTERNATIVA |
| --- |
| "Infelizmente o [imóvel X] está ocupado nesse período, mas temos o [imóvel Y] |
| que tem [características similares] e está disponível. Posso te enviar os detalhes?" |
| NÃO dizer apenas: "Está ocupado, infelizmente não posso ajudar." |
| SEMPRE oferecer alternativa da carteira antes de encerrar o atendimento. |

#### PASSO 4 — Apresentação do Imóvel e da Proposta

Enviar por WhatsApp/e-mail, de forma organizada:

- Fotos de qualidade do imóvel (galeria completa);

- Valor da diária e total do período;

- Taxa de limpeza (se aplicável);

- Caução — valor e condições de devolução;

- Regras da casa (resumo: capacidade, animais, festas, horário de silêncio);

- Política de cancelamento (clara e objetiva);

- Prazo de validade da proposta (48h padrão; 24h em alta temporada).

| COMO APRESENTAR O VALOR SEM PERDER O CLIENTE |
| --- |
| Apresentar o valor TOTAL de forma transparente — não esconder taxas. |
| "A diária é R$ X. A taxa de limpeza é R$ Y (cobrada uma vez). A caução é |
| R$ Z — ela é devolvida integralmente após a vistoria de saída, caso o imóvel |
| esteja em ordem. O total para os [N] dias é R$ [TOTAL]." |
| SE o cliente questionar o valor: |
| → Destacar o que está incluído (piscina, churrasqueira, localização, etc.) |
| → Comparar com o custo de hotel/pousada para o mesmo período |
| → Verificar se há datas com diária mais baixa que atendam |
| → Nunca oferecer desconto sem autorização do proprietário |

### Gestão de Objeções Comuns

| OBJEÇÃO | COMO RESPONDER |
| --- | --- |
| "Está caro" | Detalhar o que está incluído. Comparar com hotel. Verificar datas alternativas com tarifa menor. |
| "Não gosto de deixar caução" | "A caução é uma garantia — não é uma taxa. Ela é devolvida integralmente logo após sua saída, se tudo estiver em ordem." |
| "Posso levar mais pessoas?" | Consultar capacidade. Se não couber: "A capacidade máxima é [N] — é um requisito de segurança e conforto." |
| "Posso fazer uma festa?" | Consultar gerência antes de responder. Nunca autorizar sem aprovação. |
| "Não preciso do contrato" | "O contrato protege você também — garante a reserva, o valor combinado e as regras da devolução da caução." |
| "Posso pagar depois?" | "Conseguimos bloquear a data por 48h — mas a reserva só é confirmada com o contrato assinado e o sinal pago." |

| ⛔ O QUE NUNCA DIZER — RISCO JURÍDICO E COMERCIAL |
| --- |
| ✗ "Pode trazer mais gente, a gente não controla" → Gera superlotação, risco de dano e responsabilidade. |
| ✗ "Pode fazer festa, desde que não incomode" → Promessa sem respaldo; responsabilidade da VLA. |
| ✗ "A caução é minha, só devolvo se quiser" → Ilegal; caução tem regras contratuais claras. |
| ✗ "Não precisa de contrato, a gente é honesto" → Sem proteção jurídica para nenhuma das partes. |
| ✗ "O valor pode mudar" após envio da proposta → Gera desconfiança e cancela negociação. |
| ✗ Prometer desconto ou condição especial sem autorização do proprietário. |
| ✗ Confirmar reserva sem sinal pago — pré-reserva é apenas bloqueio de boa-fé. |

### Saídas Obrigatórias desta Etapa

- Lead registrado no CRM com origem, dados de contato e estágio do funil;

- Pré-reserva no calendário com data limite de validade;

- Proposta formal enviada por WhatsApp/e-mail com todos os itens listados acima.

## 5.2 Confirmação e Pagamento

Objetivo da Etapa

Formalizar a reserva por meio de contrato assinado e recebimento do sinal e da caução em até 48h após o envio da proposta.

### Procedimento

- Hóspede confirma proposta por escrito (e-mail ou WhatsApp);

- Coletar documentação (seção 4.1 ou 4.2);

- Gerar contrato com dados do hóspede, imóvel, datas, valor, regras;

- Enviar para assinatura eletrônica (preferencial) ou presencial em duas vias;

- Cobrar: sinal de 50% + caução integral no ato;

- Confirmar: após pagamento e contrato, alterar status para "CONFIRMADO" e enviar voucher.

### Política de Pagamento Padrão

| ITEM | VALOR | PRAZO |
| --- | --- | --- |
| Sinal | 50% do valor total da locação | No ato da reserva |
| Caução | 1 diária ou R$ 500 (o maior) | No ato da reserva |
| Saldo | 50% restantes | Até 7 dias antes do check-in |
| Taxa de limpeza | Conforme tabela do imóvel | Junto ao saldo |

#### Airbnb — Pagamento e Formalização

| AIRBNB — CONFIRMAÇÃO E PAGAMENTO |
| --- |
| Pagamento processado AUTOMATICAMENTE pelo Airbnb — nunca solicitar pagamento fora da plataforma. |
| Valor liberado ao anfitrião: 24h após o check-in, via conta bancária cadastrada (prazo bancário: 3–5 dias úteis). |
| Taxa do anfitrião ≈3%: deduzida automaticamente do valor bruto da reserva. |
| Contrato formal: para reservas dentro da plataforma, os Termos de Serviço do Airbnb substituem |
| o contrato de temporada — mas a vistoria fotográfica de entrada é OBRIGATÓRIA mesmo assim. |
| Documentação: o perfil verificado pelo Airbnb (identidade validada) dispensa coleta avulsa, |
| exceto em casos de locação especial (evento, empresa) — consultar gerência. |
| ⚠ Nunca solicitar pagamento por fora: viola os Termos do Airbnb, perde proteção AirCover |
| e pode resultar em suspensão da conta. |

| ⛔ BLOQUEIOS OPERACIONAIS |
| --- |
| Reserva NÃO é confirmada sem contrato assinado E sinal pago. |
| Pagamento do saldo após o prazo gera juros de 2% + multa de 10%. |
| Não recebimento do saldo até D-3 dispara protocolo de cancelamento (seção 6.3). |

### Atividades em D-3

- Confirmar horário aproximado de chegada;

- Enviar instruções de acesso, mapa, contato do plantão e regras da casa.

### Atividades em D-1 — Checklist

| --- | --- |
| ☐ Limpeza geral concluída | ☐ Roupa de cama/banho trocada |
| ☐ Eletrodomésticos testados | ☐ Iluminação funcionando |

#### Airbnb — Instruções de Acesso e Guia da Casa

| AIRBNB — PRÉ CHECK-IN |
| --- |
| Instruções de Acesso: configurar em Gerenciar Anúncio → Check-in e check-out → Como os hóspedes acessam. |
| → São enviadas automaticamente ao hóspede 3 dias antes da chegada. |
| → Incluir: código da fechadura/cofre, endereço completo com referências, dicas de estacionamento. |
| Guia da Casa (House Manual): disponível pelo app Airbnb durante toda a estadia. |
| → Preencher com: senha Wi-Fi, instruções dos equipamentos, regras da casa, contatos de emergência. |
| Mensagem automática D-1: configurar no Airbnb para confirmar horário de chegada e disponibilizar |
| suporte. Isso reduz no-show e antecipa dúvidas — impacta diretamente na avaliação final. |

## 5.4 Check-in

Objetivo da Etapa

Recepcionar o hóspede de forma profissional, formalizar a entrada por vistoria assinada e fotografada, e habilitar o uso do imóvel.

### Check-in Presencial (padrão)

- Recepção no horário acordado (janela de 14h às 20h, padrão);

- Conferência do documento de identidade do hóspede titular;

- Vistoria conjunta com checklist e fotos (mínimo 15 fotos);

- Apresentação do imóvel: funcionamento de equipamentos, regras, contatos;

- Assinatura do Termo de Vistoria de Entrada;

- Entrega de chaves e/ou códigos de acesso;

- Registro do horário efetivo de check-in.

### Check-in Autônomo (self check-in)

Disponível para imóveis com fechadura digital ou cofre de chaves. Hóspede recebe código 1h antes e faz vistoria via formulário com fotos em até 2h após a chegada.

#### Airbnb — Self Check-in e Registro

| AIRBNB — CHECK-IN |
| --- |
| O Airbnb valoriza o self check-in: imóveis com fechadura digital ou cofre de chaves |
| recebem destaque no filtro 'Self check-in' e têm maior taxa de conversão. |
| Código de acesso: enviar pelo chat da plataforma Airbnb (não por WhatsApp para hóspedes da plataforma). |
| → O Airbnb monitora e pode penalizar redirecionamento de comunicação para fora da plataforma. |
| Após a chegada: enviar mensagem de boas-vindas pelo chat confirmando disponibilidade para suporte. |
| Vistoria de entrada: obrigatória mesmo com self check-in — registrar via formulário com fotos datadas. |

| ✓ PADRÕES DE EXCELÊNCIA NO CHECK-IN |
| --- |
| Equipe uniformizada, identificada e cordial. |
| Imóvel iluminado e climatizado antes da chegada do hóspede. |
| Mensagem de boas-vindas escrita ou kit de cortesia visível. |
| Vistoria não pode durar mais que 20 minutos. |

## 5.5 Estadia / Suporte ao Hóspede

Objetivo da Etapa

Oferecer suporte ágil e cortês durante toda a permanência, prevenindo problemas e respondendo a demandas dentro de SLAs claros.

### SLA de Atendimento por Tipo de Demanda

| TIPO | SLA RESPOSTA | SLA RESOLUÇÃO |
| --- | --- | --- |
| Dúvida operacional (Wi-Fi, TV) | 30 minutos | 2 horas |
| Reposição de item (gás, lâmpada) | 30 minutos | 4 horas |
| Manutenção corretiva não emergencial | 1 hora | 24 horas |
| Emergência (vazamento, energia, segurança) | 15 minutos | 4 horas |

| ⚠ SINAIS DE ALERTA — AÇÃO IMEDIATA |
| --- |
| Hóspede não atende às mensagens por mais de 24h em locações ≥ 7 dias. |
| Reclamação formal de vizinho ou condomínio. |
| Indícios de excesso de hóspedes ou festa não autorizada. |

#### Airbnb — Comunicação durante a Estadia

| AIRBNB — SUPORTE |
| --- |
| Toda comunicação com hóspedes do Airbnb deve ocorrer pelo chat da plataforma. |
| → Exceção aceita: emergências — nesses casos usar WhatsApp, mas registrar resumo no chat. |
| Alterações de reserva (datas, número de hóspedes): processar sempre pela plataforma, |
| em Viagens → Alterar ou Cancelar Reserva — nunca por acerto verbal. |
| Hóspede reclamando de problema: resolver com agilidade (ver SLA acima). |
| → Uma resposta rápida e solução eficaz pode transformar um problema em avaliação positiva. |
| → Se o problema não tiver solução imediata: comunicar prazo e manter hóspede informado. |

## 5.6 Check-out e Vistoria de Saída

Objetivo da Etapa

Encerrar formalmente a estadia com vistoria documentada, identificando danos, faltas ou pendências.

### Procedimento Padrão

- D-1: Reforçar horário-limite de saída (padrão 12h; até 14h em chácaras);

- Equipe presente no imóvel ou self check-out com formulário;

- Vistoria de saída com checklist idêntico ao de entrada, com fotos comparativas;

- Conferência do inventário — utensílios, eletrônicos, mobiliário;

- Devolução de chaves e desativação de códigos;

- Assinatura do Termo de Vistoria de Saída com observações de ambas as partes.

| SITUAÇÃO | TRATAMENTO |
| --- | --- |
| Imóvel em ordem, sem danos | Liberação integral da caução em até 5 dias úteis. |
| Sujeira excessiva | Cobrança de limpeza extra; abatimento na caução. |
| Dano leve | Orçamento documentado; abatimento na caução com aceite por escrito. |
| Dano grave ou furto | Protocolo da seção 6.2; pode haver acionamento policial. |
| Atraso no check-out | Meia diária após 1h de tolerância; diária integral após 3h. |

#### Airbnb — Avaliação e AirCover

| AIRBNB — PÓS CHECK-OUT |
| --- |
| Avaliação do hóspede: acessar Viagens → Reserva → Deixar Avaliação (prazo: 14 dias após check-out). |
| → Sistema 'cego': nenhuma parte vê a nota do outro até ambos avaliarem ou o prazo expirar. |
| → Avaliar sempre, mesmo em estadias sem problemas — reforça a comunidade e o perfil do anfitrião. |
| AirCover (danos): reportar em até 14 dias após o check-out OU antes do próximo hóspede entrar. |
| → Acessar: Conta → Central de Resolução → Solicitar indenização por danos. |
| → Enviar: fotos antes/depois, orçamentos (2 cotações), nota fiscal se houver. |
| → Airbnb medeia a disputa; se não resolvida, acionar o suporte da plataforma. |

## 5.7 Pós-Estadia

Objetivo da Etapa

Encerrar financeira e operacionalmente a reserva, repassar o valor ao proprietário, capturar feedback e preparar o imóvel para a próxima estadia.

| DIA | ATIVIDADE |
| --- | --- |
| D+1 | Análise da vistoria; comunicação ao hóspede sobre liberação ou abatimento da caução. |
| D+1 | Solicitação de NPS e avaliação (1 a 5 estrelas). |
| D+2 | Devolução da caução via PIX/transferência (caso íntegra). |
| D+3 | Repasse ao proprietário do líquido apurado, com extrato detalhado. |
| D+5 | Arquivamento do dossiê completo (contrato, vistorias, fotos, comprovantes). |

#### Airbnb — Linha do Tempo da Plataforma

## 6. Cenários de Exceção

### 6.1 Inadimplência e Cobrança

#### Cenário A — Atraso no Saldo (entre D-7 e D-3)

- D-7: Lembrete cordial automatizado por WhatsApp e e-mail;

- D-5: Contato ativo da equipe comercial;

- D-4: Notificação formal — saldo deve ser quitado em 24h;

- D-3 sem pagamento: Reserva cancelada; sinal retido conforme contrato.

## 8. Gestão do Anúncio no Airbnb

Esta seção orienta a configuração e manutenção do anúncio VLA no Airbnb, garantindo visibilidade, conversão e cumprimento dos padrões da plataforma.

### 8.1 Configuração do Anúncio

| ITEM | ORIENTAÇÃO VLA |
| --- | --- |
| Fotos | Mínimo 20 fotos de alta qualidade (luz natural, ângulo amplo). Capa: área social ou fachada. |
| Título | Máx. 50 caracteres. Incluir diferencial: ex. 'Chácara com Piscina em Sorriso-MT'. |
| Descrição | Destacar comodidades, localização, público ideal. Regras da casa no campo específico. |
| Regras da Casa | Configurar: horário de check-in/out, máximo de hóspedes, não fumar, animais (sim/não), festas. |
| Política de Cancelamento | Usar 'Moderada' como padrão (reembolso 50% até 5 dias antes). Ajustar por imóvel se necessário. |

### 8.2 Precificação

| ESTRATÉGIA DE PRECIFICAÇÃO |
| --- |
| Preço Inteligente (Smart Pricing): pode ser ativado como referência, mas sempre revisar limites mínimo e máximo. |
| Definir: preço-base, preço fim de semana (15–25% maior), preço alta temporada (jul, dez-jan, feriados). |
| Taxa de limpeza: cobrar separadamente — não embutir na diária (prejudica posicionamento nos filtros de preço). |
| Desconto para semana (10%) e mês (20%): aumenta taxa de ocupação em períodos de baixa demanda. |
| Revisar precificação a cada 30 dias com base na ocupação real e nos concorrentes da região. |

### 8.3 Gestão de Calendário

- Manter o calendário sempre atualizado — bloqueios incorretos geram reservas sobrepostas.

- Bloquear datas de manutenção, uso pelo proprietário ou reservas diretas imediatamente.

- Configurar 'tempo de preparação' (buffer): mínimo 1 dia entre reservas para limpeza e vistoria.

- Estadia mínima: configurar conforme o imóvel (ex.: chácaras = 2 noites mínimo; aptos = 1 noite).

### 8.4 Reputação e Superhost

| CRITÉRIO SUPERHOST | META |
| --- | --- |
| Taxa de resposta | ≥ 90% em até 24h |
| Taxa de aceitação | ≥ 88% (evitar recusas desnecessárias) |
| Avaliação geral | ≥ 4,8 estrelas |
| Cancelamentos | 0 cancelamentos (exceto por força maior) |
| Reservas concluídas | ≥ 10 estadias ou 100 noites/ano |

| POR QUE BUSCAR O SUPERHOST |
| --- |
| Badge Superhost = maior visibilidade no resultado de busca. |
| Hóspedes filtram por Superhost — aumenta a taxa de conversão. |
| Acesso a suporte prioritário da plataforma. |
| Avaliado trimestralmente pelo Airbnb com base nos critérios acima. |
